What ships in 1.0

Sources

  • Zoom participants as separate 1080p video and audio sources
  • Webcams and capture cards
  • Screen and window capture
  • Local video clips and stills

Production

  • Scenes with Preview, Program and Take
  • CoreVideo Tiles: guests composed into one styled gallery
  • A multiviewer with Program and Preview tally
  • Graphics playout with a built-in designer, and lower thirds

Comms

  • Talk privately to people in your Zoom meeting
  • Private comms mode, so the room never hears you
  • Needs host or co-host, and talent on the Zoom desktop or mobile app

Audio

  • Routing matrix with Program and per-guest ISO taps
  • BS.1770 loudness metering
  • Bus dynamics and a limiter
  • Monitor output to any Windows audio device

Recording & streaming

  • Program and per-guest ISO MP4s on hardware encoders
  • SRT with GPU-direct HEVC or H.264, and RTMP
  • NDI output on its own switch, plus an NDI graphics key (fill and key)
  • Recording resumes on its own if the media engine restarts

Control

  • Keyboard and Stream Deck control through a Bitfocus Companion module
  • A local control API for automation
  • Redacted support bundles for troubleshooting

Before you install

  • Windows 10 or later, 64-bit, with a Direct3D 11 GPU and current graphics drivers.
  • The installer is not yet code-signed, so Windows SmartScreen may warn the first time. Choose More info → Run anyway. A signed build will follow in a 1.0.x update.
  • Setup asks for administrator approval once, to register the virtual camera.
  • First launch downloads and verifies the media runtime, so it needs internet access.

Not in 1.0: macOS, captions, the automatic scene director, and Blackmagic or AJA capture. They are not on this page because they do not ship.

Which one do I use?

Already run your shows in OBS? The free OBS plugin brings clean Zoom participants into the OBS you already have. Need only talkback, with its own operator? ZComms is the standalone desk. Want the whole studio in one app? That is CoreVideo Pro.
