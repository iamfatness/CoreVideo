Install the OBS plugin

  1. Close OBS Studio.
  2. Open the installer. On Windows, select your OBS installation folder if it is not detected. On macOS, install for your user account.
  3. Reopen OBS and follow the Operator Quickstart to sign in, join a meeting, and assign your first source.

The Windows installer is unsigned. Verify the checksum before continuing past SmartScreen’s More info and Run anyway prompts.

Verify an installer

Compare the result from PowerShell with the Windows installer checksum:

Get-FileHash .\CoreVideo-Setup-v0.1.55.exe -Algorithm SHA256

On macOS, save the installer and checksum in the same folder, then run:

shasum -a 256 -c CoreVideo-Setup-v0.1.55.pkg.sha256
Zoom, platform, and recording requirements

Sign in with a Zoom account to join meetings. The account’s Zoom entitlements and bandwidth determine the number and quality of feeds you can receive. A 1080p feed typically uses 4–6 Mbps.

For ISO recording on macOS, choose Download FFmpeg in Zoom ISO Recorder or select an existing FFmpeg executable. Talkback is available on Windows. Use OBS’s macOS Screen Capture for your own screen and CoreVideo for other participants’ shares.

See the Core Plugin Guide for workflows or Support for troubleshooting and log collection.
