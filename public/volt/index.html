Volt

Run the show from a shared rundown. Volt brings your media library, clip cues, and publishing together and keeps the same asset ID from ingest through delivery.

Install from source View source
Find the right clipIngest media and recordings, build proxies, and use transcript search to find the section you need.
Cue the rundownAttach clips and cues to rundown items. With a compatible CoreVideo Pro build, send a cleared clip to Preview and take it to Program when it’s ready.
Publish approved clipsCreate house, streaming, and social versions from the approved clip and track the delivery URLs on its rundown item.

Run Volt

The session runs as a service with a browser-based operator interface. A source installation requires Python 3.12 or newer, FFmpeg, and ffprobe. The operations guide covers setup, storage, health checks, and connecting to CoreVideo Pro.
